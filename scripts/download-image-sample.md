# 单车型图片样本（只下载，不同步飞书）

先在已挂载的外接盘 `/Volumes/奥睿科1TB/代码程序/汽车之家爬虫图片库` 中创建一个样本文件夹，在其中保存 `candidates.json` 数组。每项必须包含：

```json
{
  "id": "exterior-01",
  "category": "不同角度外观",
  "title": "左前方外观",
  "url": "来源页面实际提供的 HTTPS 图片地址",
  "source_page": "可人工打开核对的来源页面",
  "identity": "车系、配置ID、年款或官网素材适用范围限制",
  "classification_basis": "图库标签或官网栏目；具体角度还需看图确认"
}
```

从仓库根目录运行：

```bash
bun scripts/download-image-sample.ts "/Volumes/奥睿科1TB/代码程序/汽车之家爬虫图片库/你的样本文件夹"
```

该入口复用项目请求节流与风控停止机制，串行下载，间隔至少 5 秒。只允许指定比亚迪官网及汽车之家图片域名，不自动跟随重定向。校验图片解码、尺寸及内容哈希，原件、缩略图、来源回执均保存在样本目录；磁盘未挂载或目标在图库外时停止。同目录重跑校验已下载原件并复用，不重新请求。

这不是通用视觉分类器：先通过来源标签限定车型和类别，再人工看图确认角度、重复构图及适用版本。官方展示图不等于某款配置的实拍或标配证明。脚本不读取或写入飞书，用户确认样本后再单独确定同步范围。
